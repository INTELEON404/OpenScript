Click any language below to view the available scripts:

---

## ⚡ Execution & Viewing via `tee`

Run any script by name while saving the console output to a log file using `tee`:

```bash
# JavaScript
node js/app.js | tee js_output.log

# Python
python3 python/main.py | tee python_output.log

# Bash
./bash/setup.sh | tee bash_output.log

# Go
go run go/tool.go | tee go_output.log

```
